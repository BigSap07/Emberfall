# Emberfall stage fingerprint baseline.
#
# One line per shipped campaign stage per sampled seed:
#   <stage>|<seed>|<fnv1a-64 of the battle's whole event stream>.
# The battle is the stage's OPENING one, fought by a fresh profile's starting
# three, so a line moves when that stage's authored roster or levels move, or
# when the engine or a starter's kit changes under it.
#
# A MOVED LINE IS A CONTENT OR BEHAVIOUR CHANGE. It needs a stated reason in the
# commit that moves it. Regenerating to make a surprise go away is how a guard
# stops guarding.
#
# The whole event stream behind a hash:  EMBERFALL_DUMP_STAGE_FP=1
# Regenerate deliberately:               EMBERFALL_REGEN_STAGE_FP=1
#
# WHY 60 OF THESE 72 LINES MOVED.
#
# Tools/solve-recommended-power.ps1 re-derived recommendedPower for all 24 stages and
# the levels underneath it. The kit and rarity passes had merged after the hand
# derivation on balance/campaign-curve and made the simulated player's line a few
# percent stronger, so entry power rose while recommendedPower stood still and six
# stages drifted over the high edge of their band. The tool is that derivation as a
# command: entry power over the middle of each stage's band, then floorLevel,
# ceilingLevel and the authored enemy levels re-solved under the answer.
#
# A fingerprint here is the stage's OPENING battle, which is the authored roster at
# floorLevel, so it moves exactly when that roster moves and not when a ceiling does.
# One line per stage, and the four that did not move say so rather than being omitted:
#
#   1-1    unmoved  roster 2/2/2 untouched; recommendedPower held at 2,977 and no level moved
#   1-2    unmoved  roster 6/6/6 untouched; recommendedPower 3,759 -> 3,797 needed no level
#   1-3    MOVED    roster 9/9/10 -> 10/10/11, floorLevel 10 -> 11, ceiling 12 -> 13
#   1-4    MOVED    roster 12/11/12 -> 13/12/13, floorLevel 12 -> 13, ceiling 15 -> 16
