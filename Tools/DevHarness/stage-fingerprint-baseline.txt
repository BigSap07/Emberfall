# One line per shipped campaign stage per sampled seed:
#   <stage>|<seed>|<fnv1a-64 of the battle's whole event stream>.
# The battle is the stage's OPENING one, fought by a fresh profile's starting
# three, so a line moves when that stage's authored roster or levels move, or
# when the engine or a starter's kit changes under it.

# A MOVED LINE IS A CONTENT OR BEHAVIOUR CHANGE. It needs a stated reason in the
# commit that moves it. Regenerating to make a surprise go away is how a guard
# stops guarding.
#
# The whole event stream behind a hash:  EMBERFALL_DUMP_STAGE_FP=1
# Regenerate deliberately:               EMBERFALL_REGEN_STAGE_FP=1
#
