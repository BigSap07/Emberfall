# Emberfall stage fingerprint baseline.
#
# One line per shipped campaign stage per sampled seed:
#   <stage>|<seed>|<fnv1a-64 of the battle's whole event stream>.
# The battle is the stage's OPENING one, fought by a fresh profile's starting
# three, so a line moves when that stage's authored roster or levels move, or
# when the engine or a starter's kit changes under it.
#
# A MOVED LINE IS A CONTENT OR BEHAVIOUR CHANGE. It needs a stated reason in the
# commit that moves it. Regenerating to make a surprise go away is how a guard
# stops guarding.
#
# The whole event stream behind a hash:  EMBERFALL_DUMP_STAGE_FP=1
# Regenerate deliberately:               EMBERFALL_REGEN_STAGE_FP=1
#
# WHY 36 OF THESE 72 LINES MOVED, AND WHICH 36.
#
# Tools/solve-recommended-power.ps1 re-derived recommendedPower for all 24 stages and
# the levels underneath it, because the 3-star authoring pass changed what a player can
# field. Adric is one of the five bodies PlayerProfile.NormaliseTeam has deployed on the
# simulated player's line and he was the last placeholder kit among them, so giving him a
# real one moved the whole economy walk: entry power rose, recommendedPower stood still,
# and 2-12 drifted to x1.08 against a x1.02 ceiling. The solver is that derivation as a
# command - entry power over the middle of each stage's band, then floorLevel,
# ceilingLevel and the authored enemy levels re-solved under the answer. It converged in
# sixteen iterations and moved 22 of 24 stages.
#
# A fingerprint here is the stage's OPENING battle, which is the authored roster at
# floorLevel, so it moves exactly when that roster moves and not when a recommendedPower
# or a ceiling does. Twelve of the 22 moved a roster; those twelve are the 36 lines, at
# three sampled seeds each. One line per stage, and the twelve that did not move say so
# rather than being omitted:
#
#   1-1    unmoved  roster 2/2/2 untouched; recommendedPower held at 2,977
#   1-2    unmoved  roster 6/6/6 untouched; recommendedPower held at 3,797
#   1-3    unmoved  roster 10/10/11 untouched; recommendedPower 4,806 -> 4,733 needed no level
#   1-4    unmoved  roster 13/12/13 untouched; recommendedPower 4,959 -> 4,887 needed no level
#   1-5    unmoved  roster 15/15/16/14 untouched; recommendedPower 5,031 -> 4,958 needed no level
#   1-6    unmoved  roster 18/18/18/18 untouched; ceiling 23 -> 22 alone, which no opening battle reads
#   1-7    MOVED    roster 22/22/21/22 -> 21/21/20/21, floorLevel 22 -> 21, ceiling 28 -> 27
#   1-8    unmoved  roster 16/20/20/20 untouched; recommendedPower 5,986 -> 5,948 needed no level
#   1-9    MOVED    roster 16/13/23/23/23 -> 15/13/22/22/22, floorLevel 23 -> 22, ceiling 26 -> 25
#   1-10   unmoved  roster 17/11/17/17/17 untouched; recommendedPower 6,671 -> 6,636 needed no level
#   1-11   unmoved  roster 12/11/17/17/16 untouched; recommendedPower 7,068 -> 7,018 needed no level
#   1-12   unmoved  roster 15/11/11/12/12 untouched; the finale's 8,767 -> 8,753 needed no level
#   2-1    unmoved  roster 35/34/35 untouched; recommendedPower 8,177 -> 8,167 needed no level
#   2-2    MOVED    roster 37/38/36 -> 37/39/36, floorLevel 38 -> 39, ceiling 42 -> 43; one unit alone
#   2-3    unmoved  roster 35/40/34 untouched; recommendedPower 9,990 -> 9,956 needed no level

#   2-6    MOVED    roster 42/40/43/43 -> 44/43/45/45, floorLevel 43 -> 45, ceiling 59 -> 61
#   2-7    MOVED    roster 50/42/42/41 -> 53/46/45/44, floorLevel 50 -> 53, ceiling 55 -> 59

#   2-11   MOVED    roster 66/61/56/53/51 -> 72/67/62/58/56, floorLevel 66 -> 72, ceiling 71 -> 77
#   2-12   MOVED    roster 48/36/31/50/50 -> 52/41/36/54/54, floorLevel 50 -> 54, ceiling 57 -> 61
#
# THE DIRECTION SPLITS BY CHAPTER, and that is the reading rather than a surprise. Chapter 1
# came DOWN - 1-7 and 1-9 each lost a level off every body - because a chapter-1 player has
# not yet levelled the new kit and the derivation found entry power slightly under where the
# hand table had assumed it. Chapter 2 went UP, by three to six levels a body at the deep end,
# because by 2-7 the simulated player has had Adric's kit working for a whole chapter and the
# economy compounds it. 2-12 is the largest single move in the table, at +1,878
# recommendedPower.
#

# starter kit change is in this regenerate. None of the eighteen 3-stars is a starting hero, so
