# Ability text pass: every rewrite, before and after

Recorded on 2026-09-22, when every ability description was rewritten to say what happens without
quoting a number (see `Docs/ABILITY-TEXT-STYLE.md`). This file lists the **147 descriptions that
already had text** and were changed. Text written where there was none is not listed here; it is
in `heroes.json`.

Three of these were drafting notes whose question `Docs/PINOY-LIST.md` section 2c records as closed
(Orenna, Piri, Wynn), so the note came off with the number. Every other drafting note was left as
written and is a question in section 2f.
